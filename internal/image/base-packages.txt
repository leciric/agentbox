# The Debian packages every AgentBox runtime installs before any agent tool, in
# one list because all three run the same commands: the Incus base image
# (system.sh), the pod image an agent runs as in a cluster
# (internal/agentimage/Dockerfile) and the daemon container
# (packaging/daemon/Dockerfile). Read by all three, so a package an agent's work
# turns out to need is added here once and arrives everywhere. A runtime that is
# missing one of these fails in a way that looks like the tool's own fault: a
# Claude Code login with no curl says "curl: command not found" after the
# download has already been announced, which is what this file is for.
#
# One package per line; comments and blank lines are skipped. Machine-only
# pieces stay out and are installed by the runtime that has them: sudo (the
# Incus user's passwordless sudo), Docker, mise, the desktop, Mesa and the
# optional components.
